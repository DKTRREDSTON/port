# Nasser Wael Abbas Portfolio

## تشغيل المشروع

1. ثبّت Node.js LTS من https://nodejs.org
2. افتح PowerShell داخل هذا المجلد
3. نفّذ: `npm install`
4. للتشغيل أثناء التعديل: `npm run dev` ثم افتح http://localhost:5173
5. لإخراج نسخة HTML ثابتة: `npm run build:static`
6. افتح الملف الناتج: `dist/public/index.html`
